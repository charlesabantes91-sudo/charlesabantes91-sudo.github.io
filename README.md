# Charles Abantes — Professional Portfolio

A responsive, single-page portfolio website for GitHub Pages. The design uses a modern black, white, and blue palette.

## Files
- `index.html` — portfolio content and page structure
- `style.css` — responsive layout and visual styling
- `script.js` — mobile navigation and current year
- `samples/` — clearly labeled fictional practice samples

## Before publishing
1. Replace the email placeholder in the Contact section with your real professional email.
2. Update the `mailto:` link in `index.html` to `mailto:YOUR_EMAIL_ADDRESS`.
3. Upload your latest PDF resume and add a link to it in the Contact section.
4. Add a real professional profile photo if you want one; the current design uses initials (CA).
5. Review every skill and tool listed. Keep only tools you can confidently demonstrate.
6. Do not describe the practice samples as paid client work.

## Publish with GitHub Pages
1. Sign in to GitHub and open your repository: `charlesabantes91-sudo.github.io`.
2. Download and unzip this portfolio package.
3. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `samples` folder to the repository's root (not inside another nested folder).
4. Commit the changes to the `main` branch.
5. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. Wait for GitHub Pages to finish deploying. Your site should be available at:
   `https://charlesabantes91-sudo.github.io/`

If the repository already contains a live portfolio, download or back up its current files before replacing them. This package has not been uploaded to GitHub automatically.
